# 실기 필답형 11권 원천 스윕

기준일: 2026-08-10  
범위: 설비보전기사 실기 **필답형 이론**과 복원·예상문제의 연결 구조  
제외: 공압·유압·용접 작업형 타이머 UI, 배포, DB 반영

## 결론

기존 데이터는 NCS 교재 11권을 모두 참조했지만, 책 안의 세부학습단위까지 내려가면 61개 중 34개만 기존 개념과 직접 연결되어 있었다. 책 단위의 `11/11 covered`를 전 범위 학습 완료로 해석하지 않도록 목차의 61개 단위를 별도 원천 레지스트리로 만들고, 비어 있던 27개에는 시험형 암기 캡슐·필수어·문제유형·예상문제 씨앗을 배치했다.

이후 27개 후보를 각각 독립 검수해 **NCS 보강 이론 27개와 자체 예상문제 27개**로 승격했다. 문제는 실제 기출·복원이 아니라 `predicted_exam`·`ncs_supplement`로 표시하고, 출제 회차는 부여하지 않는다. 법령·표준·제조사·WPS에 따라 달라지는 수치는 고정 답안에서 제외했다. 이로써 61개 세부학습단위 모두 공개 이론과 연결되며, 원래 후보 레코드의 `editorial_hold`는 자동발행 전 검토 이력을 보존하는 값으로만 남는다.

## 재조립 원칙

학습 흐름은 아래 순서를 따른다.

`NCS 교재 → 세부학습단위 → 출제유형 → 연결 복원기출 → 제출 후 답안 → 필수어 → 변형·예상문제 씨앗`

- 복원기출이 있는 단위는 A로 두고 실제 출제 연결을 먼저 보여 준다.
- 기존 예상문제나 인접 개념만 있는 단위는 B로 둔다.
- 직접 연결이 없던 단위는 NCS 원문의 학습목표·핵심 절차로 짧은 암기 캡슐을 만들고, 정의·배경·구성요소·절차·진단·안전·오답함정을 갖춘 독립 보강 이론으로 승격한다.
- 각 보강 이론에는 텍스트만으로 답안조건이 완결되는 자체 예상문제 1개, 모범답안, 필수어, 채점항목, 암기팁을 연결한다.
- 법령 수치, 보호구 등급·교체주기, 용접 전류·예열·층간온도는 최신 공식 근거 또는 적용 WPS 확인 전 수치형 문제로 만들지 않는다.
- 새 예상문제는 기존 복원문제의 원문을 바꾸지 않으며, 복원문제 수·출제횟수에도 포함하지 않는다.

## 자동 검증

`npm run verify:practical-source-sweep`는 다음을 실패 조건으로 검사한다.

- 11권과 현재 생성 콘텐츠의 NCS 코드 집합 불일치
- 목차 쪽수 범위의 중복·단절
- 기존 NCS 출처가 61개 단위 중 정확히 하나에 귀속되지 않는 경우
- 공개 개념이 없는 세부학습단위
- 후보 27개와 승격 레코드의 누락·중복·학습단위 불일치
- 승격 문제의 모범답안·필수어·채점기준·NCS 출처·이론 연결 누락
- 존재하지 않는 인접 개념·복원문항 연결
- 미추출 복원 출처에 회차나 문항을 임의로 부여한 경우
- 원천 변경 뒤 생성 감사파일을 갱신하지 않은 경우

현재 문제·개념 행 수는 관측값으로만 사용하며 새 영구 불변식으로 고정하지 않는다. 교재 목차나 생성 콘텐츠가 의도적으로 바뀌면 원천 레지스트리와 감사파일을 함께 다시 생성·검토한다.

세부학습단원 시작 전의 문서 서두 1~2쪽에 적힌 수행준거를 참조한 경우는 본문 쪽수를 위조하지 않는다. 감사파일에 `documentLeadInSourceReferenceCount`로 별도 기록하고 해당 문서의 첫 세부단원에 귀속한다.

## 공개 승격 검수 결과

27개 후보는 다음 조건을 모두 만족하는지 자동 검사한 뒤 실제 이론과 예상문제로 승격했다.

1. 문제 문장과 정답 범위가 서로 일치한다.
2. 답안 필수어와 채점 기준을 독립 검토한다.
3. 법령·안전·표준·제조사·WPS 조건에 종속되는 수치나 등급은 고정 답안으로 쓰지 않는다.
4. 그림·기호·도면 없이도 답안조건이 완결되게 구성하고, 이미지가 필수인 문제는 만들지 않는다.
5. 제출 전 정답·해설·선택지 피드백 누출 검사를 통과한다.
